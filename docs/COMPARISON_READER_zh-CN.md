# 左右对照阅读

本地界面分为上传页和独立的全窗口阅读页：左侧原文、右侧译文，翻译成功后自动进入阅读页，原来的译文 PDF 和双语 PDF 下载功能保留。

## 使用

1. 打开首页，上传 PDF 并配置翻译服务。
2. 开始翻译。成功后自动跳转到占满窗口的原文／译文对照阅读页；失败或取消时保留上传页。
3. 默认开启「同步滚动」，在任意一侧滚动都会同步另一侧的页码和页内位置。取消勾选后可以独立阅读。
4. 使用上一页、下一页或输入页码跳转；选择适合宽度或 100%–200% 缩放。全屏按钮用于扩大阅读区域。
5. 原生 PDF 文本可选择和复制。原文与译文的图形、公式直接从各自 PDF 渲染。

打开首页始终显示上传页；可以点击侧栏中的最近译文文件名打开结果，不再翻译。阅读页左上角提供返回上传页入口，右上角菜单提供译文及双语 PDF 下载链接。阅读器自动占满窗口，无需点击全屏按钮；全屏按钮仍可用于隐藏浏览器自身界面。翻译预览不会额外调用翻译 API。

界面参考一个本地项目重新设计：上传页使用米白底色、灰绿色侧栏、最近译文入口和深青色按钮。左侧最近译文显示文件名，点击即可继续阅读。阅读页默认只显示 48 像素工具栏；缩放、同步开关、下载与浏览器全屏位于右上角「•••」菜单。「隐藏工具栏 · 专注阅读」会让正文占满窗口，可按 Esc 或点击右下角按钮恢复。

## 当前范围

- 同步是按 PDF 页码和页内相对位置进行，尚未实现句子／段落语义匹配及关联高亮。
- 原文与译文页数不一致时会显示提示，以相同页码匹配，超过较短文档范围时停在末页。
- 页面图像及文字层按需加载，资源由本地服务提供，不依赖外部 PDF 预览 CDN。文字层用于选择和复制，扫描图像本身没有可选择的文字。
- 在高倍缩放时页面图像的锐度受预览分辨率限制；下载的 PDF 不受影响。
- Word 文件上传后需要先完成转换及翻译，才能显示 PDF 对照预览。

实现位于 `pdf2zh/comparison.py` 和 `pdf2zh/reader/`，通过同一服务的 `/compare` 路由提供阅读器及页面资源。

## 模型设置

上传页右上角「模型设置」显示当前翻译服务和模型。点击后可选择服务，编辑接口地址、API Key 和模型名称；流式响应、停止标记及输出长度位于「接口高级参数」。点击「保存设置」会立即写入本机配置，无需开始翻译，刷新页面或重启服务后自动恢复。点击「取消」会恢复上次保存的配置。

API Key 默认遮挡，勾选「显示 API Key」可临时显示；重新打开设置或刷新后恢复遮挡。配置仍沿用项目原有的本机配置文件。语言、页码和排版参数保留在上传页。阅读页右上角菜单中的「模型与接口设置」可返回上传页并直接打开设置弹窗。

验证：3 个后端测试覆盖文档元数据、页面渲染与文字、原文单栏、无效页码／未注册文档／非法资源，以及最近译文发现；界面检查覆盖同步翻页、双向滚动、独立滚动、缩放、越界页码和上传状态清除。未重新调用付费翻译 API。
